# NBA 2K27 Cheats

Static Astro site for NBA 2K27 cheats — Auto Green, Court Vision, MyTeam overlays, VC tools, and live 2K Anti-Cheat status — Cloudflare Workers ready.

Rebranded from the [dayzcheats.io](https://github.com/Stellarhamza/dayzcheats.io) template for local development.

```bash
npm install
npm run dev
npm run build
npx wrangler deploy
```

Dev server: **http://localhost:5174**
